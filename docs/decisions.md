## 一、技术与架构

| # | 决策 | 结论 | 依据 | 裁定人 | 日期 |
|---|---|---|---|---|---|
| D1 | 后端框架 | **FastAPI**（不用 Flask / DRF） | 自带 OpenAPI，契约可被验收脚本直接读；Pydantic 入参校验能从机制上堵死"接口收前端身份参数" | Owner | 2026-09-28 |
| D2 | 前端框架 | **Vue 3 + Vite + TypeScript** | 与 Owner 既有技术经验一致；产品经理原建议 React+TS 未被采纳 | Owner | 2026-09-28 |
| D3 | 样式层 | **只用 Tailwind 一套** | 双层样式系统（如 MUI + Tailwind）会互相打架，且增加维护面 | Owner | 2026-09-28 |
| D4 | 数据库 | **PostgreSQL 16** | 金额 `BIGINT`；部分唯一索引可在数据库层兜底"同房间同用户唯一有效成员" | Owner | 2026-09-28 |
| D5 | 执行模型 | **同步**（`def` 端点 + 同步 Session） | V1 并发量极低；同步实现的事务边界与堆栈可读性优于 async，FastAPI 会把 `def` 端点放进线程池 | Owner | 2026-09-28 |
| D6 | 密码哈希 | **直接用 `bcrypt` 库**，不用 passlib | passlib 1.7.4 与 bcrypt 4.x 存在已知不兼容 | Owner | 2026-09-28 |
| D7 | 金额表示 | **全程整数分**（DB `BIGINT` / API `int`） | 只要有一条路径用 float，"分摊之和等于总额"就只是时间问题 | Owner | 2026-09-28 |
| D17 | 前端服务形态 | **nginx 托管构建产物 + `/api` 同源反代** | 浏览器与后端同源，从结构上消灭通配 CORS 这一类问题 | Owner | 2026-09-28 |

## 二、业务规则

| # | 决策 | 结论 | 依据 | 裁定人 | 日期 |
|---|---|---|---|---|---|
| D8 | 分摊范围 | **V1 只做均分**，不等额分摊留 P1 | 砍掉一整类边界问题，让 B3 断言保持干净 | Owner | 2026-09-28 |
| D9 | 结算余数归属 | **最大余额法**（均分场景下退化为按 userId 升序分配） | 规则确定性最强、无人为偏好；并列时以 userId 升序打破平局 | Owner | 2026-09-28 |
| D10 | 结算后状态 | **只读，不可回滚** | 幂等语义只保留一套；允许回滚会让 B5 变成两套语义 | Owner | 2026-09-28 |
| D11 | 房间人数上限 | **默认 20，配置可改** | 有上限才测得出边界；不写死是因为以后要调 | Owner | 2026-09-28 |
| D12 | 账户体系 | **仅用户名 + 密码** | V1 不引邮件服务，省掉一整条未验证链路 | Owner | 2026-09-28 |
| D15 | 文件上传 | **V1 不做**（C6 验收标 N/A） | 上传是历史上最容易出事的一块（目录裸奔、文件入库），V1 不引入 | Owner | 2026-09-28 |
| D16 | 越权返回码 | **403（而非 404）** | 便于 C1 断言；代价是暴露"资源存在"这一信息。信息面收敛留待后续加固，此处显式记录该取舍 | Owner | 2026-09-28 |
| D21 | 账单删除权限 | **仅房主可删** | V1 取最少而确定的规则；"付款人本人也可删"待 Owner 评估 | Owner | 2026-09-28 |

## 四、已否决 / 明确不做

| 项 | 内容 | 理由 |
|---|---|---|
| N1 | 推荐算法、智能风控、AI 行程规划等需要"指标"（准确率 / 召回率 / AUC）验收的功能 | 需要标注数据与评估流程，个人项目会变成做不动的科研项目 |
| N2 | 任何需要训练模型的功能 | 同上，且与 V1 三项交付无关联 |
| N3 | 任何需要数据集 / 对照组 / 论文对比的功能 | 同上 |
| N4 | 旅伴智能匹配 / 推荐排序 | 落入 N1 |
| N5 | 数据统计 / 可视化大屏 | V1 无数据量，产出无意义 |
| N6 | 管理后台 | 为后台单独设计权限体系会直接扩大 P0-3 的范围 |
| N7 | 不等额分摊（自定义每人份额） | 留 P1；V1 均分即可覆盖主链路 |

判定信号：**只要验收标准里出现准确率 / 召回率 / AUC / 训练 / 数据集 / 对照组，就是越界。**
